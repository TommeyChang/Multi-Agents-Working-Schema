# 技能：跑大命令自保（宿主与上下文都别顶坏）

## 何时用
要跑全量测试／大范围扫描／长任务；或一条命令被外部 `SIGTERM` 截断过（exit 143）。

## 为什么有它（实测事故）
- 10-03：单个 pytest 跑 2004 例涨到 3.4G 常驻 ＋ 7.2G swap，整机进 D 状态、dsh 假死 20s。
- 10-04：两个孤儿 xdist worker 空转 1h49m，写 40GB ＋ 32GB，磁盘 1.5h 从 73G 涨到 136G。
- 同因：agent 命令与 dsh 本体同 cgroup（DSH 的 bash 工具硬编码 `bash -c`，无 cgroup 开关）。
- 取样与判据见 `ops/qcta/README.md`。

## 四条做法
1. **输出落盘**：大输出写文件，只回报「命令 ＋ 退出码 ＋ 摘要数字 ＋ 路径」——别 `cat` 大文件、别 `ls -R` 打全树。
2. **分批取代长跑**：长任务拆成多批短跑（我实测单次长跑会被外部 SIGTERM 截断；分批每次都能拿到 rc）。
3. **限并发**：真库档不得并发；pytest 并发按额度来，别一次开十个。
4. **事后清点**：跑完查 `df -h` 与 `ls -d /tmp/pytest-* | wc -l`；孤儿目录按**创建者 PID 是否还活着**判（不是按 mtime）。

## 写文档时
`python3 tools/context_budget.py` 看冷启动与按需面预算；超了先删，别抬上限（要抬写明理由）。
