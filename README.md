# MAWS — Multi-Agents Working Schema

一套**多代理协作体系**：人读的规则（本目录）＋ 机读的协调器（`coordinator/`），**两者可对账**。

给一组 AI 会话（指挥官、产品负责人、技术负责人、工程师、运维、DBA……）定**角色、权限、
任务状态机与资源账目**，让它们在同一份事实上协作，而不是各自读一堆散文再自行理解。

| 件 | 在哪 | 作用 |
|---|---|---|
| **入口 ＋ 规则** | `AGENT.md` ＋ `rules/` | **人读**：谁在什么条件下做什么 |
| **角色** | `agents/` | **人读**：一角色一文件，统一骨架 |
| **协调器** | `coordinator/` | **机读**：唯一写入口，状态与资源的权威 |
| **取样件** | `ref/`（**不入库**） | 只读参考：从别的项目取来的原件，改东西时对样子用 |

## 从这里开始

1. 读 [`AGENT.md`](AGENT.md)（约 1.3k tokens）——它告诉你这个体系是什么、目录怎么摆、下一步读什么；
2. 按你的角色读 `agents/<角色>.md`；
3. 需要查动词、状态、不变量的**具体判据**时，再读 `rules/` 下对应文件（**按需读，不预读**）。

**上下文是稀缺资源**：本体系刻意把"必须读的"压到最小，其余按需取用。

## 跑协调器

协调器只用**标准库**（`python3` 即可，不依赖任何第三方包）：

```bash
cd coordinator
coord init                       # 初始化状态根（默认 <体系根>/.state）
coord maws                       # 打印体系定义，**并与实现对账**
coord status                     # 一行摘要
coord report                     # 人读报告（只列异常与待决）
coord ready --role-name tech-lead  # 本线可认领清单
coord trace <id>                 # 正查：这条目凭什么算完成
coord why <path>                 # 反查：这个文件为什么是这个样
```

`tools/` 下是本体系自己的工具（门禁入口、迁移闸、登记闸、合并封装、影响面、预算标定、
监视器、冒烟等），每个都能 `--help` 自证用法：

```bash
python3 tools/gate.py --changed <改动的文件…>   # 门禁：ruff ＋ 按影响面跑测试，产出证据四件套
python3 tools/smoke.sh                          # 冒烟：端到端一口气跑通（58 项）
python3 tools/calibrate.py                     # 按真实负载量并行度上限，给逐线预算**建议**
```

## 四条不可协商的底线

1. **交接走记录**：一切任务状态的变更只经协调器，任何人不直接编辑状态文件；
2. **锁在协调器**：认领／定稿／交付／验收都带期望版本号，基于过期快照的请求必被拒绝；
3. **证据必落盘**：门禁证据 ＝ 命令 ＋ 退出码 ＋ 摘要 ＋ 原始输出路径（＋收窄了测试范围时的口径）；
4. **协调器不判内容**：它只判形式，实质验收归人。

## 两条工程纪律

- **本体系自持**：不引用外部工具，只驱动目标仓的**内容**（它的测试、迁移件、diff）与系统工具 `git`；
  外部能用得上的部分已经**并进来**（见 `coordinator/tools/README.md` 的改造总账）。
  这条由 `coordinator/tests/test_selfcontained.py` 钉住。
- **决策缺口必须暴露，不能靠默认值静默填上**：预算逐线批、号是资源、量大不出来就说量不出来。

## 测试

```bash
cd coordinator
python3 -m pytest -q        # 420 项
python3 -m ruff check .     # 静态检查
bash tools/smoke.sh         # 端到端冒烟（58 项）
```

## 关于 `ref/`

`ref/` 装的是**从别的项目取来的原件**（真实任务板与工具源码），仅作本地对照参考，
**故意不入库**（见 `.gitignore`）；出处、源提交与逐文件哈希记录在它自己的 `README.md` 里。
